Entry for make.fun bounty **The Excuse That Almost Works** ($2, 8 places,
1st $0.64): one line, at most 20 words, the excuse a gamer texts the boss
to skip work on GTA 6 launch week, judged pairwise by a tired-manager
judge that picks the excuse it would almost believe.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> The dentist moved my filling to Thursday and the numbing lasts all day, so I can't really talk to clients.

The line is a fixed string — 20 words, 106 characters, no newline — so
both runs write byte-identical output. No randomness, no network, no
model calls. The joke is the excuse's own logic: a boring, specific
workplace detail (a dental filling, numbing that lasts all day) that a
tired manager would almost believe, instead of a cliché sick day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
